# Hardware Specifications

> **Status:** Draft — placeholder content. Final technical prose is forthcoming.


Model S-1000 (DIN-Rail), S-5000 (1U), and V-Edge (Virtual VM).

## S-1000

DIN-rail rugged unit for substations and field cabinets: RK3588 or Atom class compute, bypass relays.

## S-5000

1U rackmount for datacenters: dual Xeon/EPYC plus L4-class GPU, 10/25/40GbE line rate.

## V-Edge

Hardened VM image (OVA/QCOW2) for existing virtual clusters with vTPM support.
