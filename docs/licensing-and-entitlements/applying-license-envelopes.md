# Applying License Envelopes (`license.lic`)

Once an offline license envelope is generated by Aryorithm, apply it to the edge appliance without interrupting running network links.

---

## 1. Installation Procedure

1. Copy the received `license.lic` file to the appliance via secure USB, SCP, or management console.
2. Place the license file in the root configuration directory:
   ```bash
   sudo cp license.lic /etc/sentinel/license.lic
   sudo chmod 644 /etc/sentinel/license.lic
   sudo chown root:root /etc/sentinel/license.lic
   ```
3. Validate the license envelope using the CLI tool:
   ```bash
   sentinel --validate-license /etc/sentinel/license.lic
   ```

### Expected Output

```text
[*] Inspecting /etc/sentinel/license.lic...
[+] Asymmetric Ed25519 Digital Signature: VALID (Signed by Aryorithm CA)
[+] Tenant Identity : Municipal Water & Power Authority (Munich East)
[+] License Tier    : ENTERPRISE_OT (All 26 Subsystems + 30 Dissectors)
[+] Expiration Date : 2027-10-05 00:00:00 UTC (365 Days Remaining)
[+] Hardware Locking: MATCHED (Bound to Infineon TPM 2.0 Silicon PCR 0)
[+] Status: LICENSE ENVELOPE VERIFIED AND APPLIED.
```

---

## 2. Live In-Process Reloading

If the `sentinel` daemon is already executing, reload the license without restarting the process or dropping network connections:

```bash
# Send SIGHUP to trigger live license re-reading
sudo systemctl reload sentinel
```

Check the system journal to confirm entitlement updates:

```bash
journalctl -u sentinel -n 20 --no-pager | grep -i license
```
